# 参考资料

以下资料用于确认扩展结构、侧边栏 API、主题 JSON 格式和 Registry 元数据。框架没有复制这些项目的源码。

## ComfyUI 官方文档

- JavaScript 扩展概览：<https://docs.comfy.org/custom-nodes/js/javascript_overview>
- 侧边栏标签页：<https://docs.comfy.org/custom-nodes/js/javascript_sidebar_tabs>
- 外观与主题：<https://docs.comfy.org/interface/appearance>
- 自定义节点概览：<https://docs.comfy.org/custom-nodes/overview>
- Registry 发布：<https://docs.comfy.org/registry/publishing>
- `pyproject.toml` 规范：<https://docs.comfy.org/registry/specifications>

## 官方仓库

- ComfyUI：<https://github.com/Comfy-Org/ComfyUI>
- ComfyUI Frontend：<https://github.com/Comfy-Org/ComfyUI_frontend>

## 浏览器 API

- File API / FileReader：<https://developer.mozilla.org/docs/Web/API/File_API>
- Canvas `getImageData`：<https://developer.mozilla.org/docs/Web/API/CanvasRenderingContext2D/getImageData>
- EyeDropper API：<https://developer.mozilla.org/docs/Web/API/EyeDropper_API>

## 版本提醒

ComfyUI Frontend 仍在快速迭代。主题字段和内部实现可能变化，应优先从目标版本的 ComfyUI 设置中导出主题作为编辑基准。
