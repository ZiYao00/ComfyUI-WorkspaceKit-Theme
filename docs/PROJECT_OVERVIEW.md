# 项目说明

## 项目名称

- 仓库：`ComfyUI-WorkspaceKit-Theme`
- 产品显示名：`WorkspaceKit Theme Lab`
- 当前阶段：可运行 Alpha，版本 `0.1.0`

## 定位

WorkspaceKit Theme Lab 是 WorkspaceKit 系列中的主题设计工具。它不提供模型推理节点，而是一个纯客户端 ComfyUI 扩展，通过真实 ComfyUI 画布对主题参数进行即时预览。

## 解决的问题

传统的 ComfyUI 主题修改流程通常是：导出 JSON、查找不直观的键名、手工修改、重新导入、刷新或反复确认。这个流程存在以下问题：

- 参数名难以对应实际界面。
- HEX、RGBA、透明度编辑不直观。
- 需要反复导入才能确认效果。
- 容易把错误状态、Bypass 状态和 Never 状态混淆。
- 从参考图片取色需要借助其他软件。

本项目把流程改为：

```text
导入主题 → 选择参数 → 实时修改真实界面 → 参考图精确取色/推荐色 → 导出主题
```

## 设计原则

1. 真实优先：使用宿主 ComfyUI 画布，不自行绘制仿制节点。
2. 复用优先：使用 ComfyUI 侧边栏、运行时画布、CSS 变量和官方主题 JSON 结构。
3. 临时预览与持久化分离：调色时不写设置；确认后再导出或保存。
4. 兼容性隔离：所有宿主版本差异集中在 `theme_runtime_adapter.js`。
5. 数据无损：未知字段保留，避免导出时破坏新版本或第三方主题字段。
6. 本地优先：不依赖远程 CDN 或额外 Python 包；推荐色算法以固定版本的 MIT Vendor 随插件发布。
