# 后续计划

## 当前基线：0.1.0 Alpha

已完成：WK 合并/独立双模式、共享四分区 UI、主题 JSON 导入导出、当前界面读取、字段级实时预览、撤销/重做、参考图精确取色、屏幕吸色和 8 色推荐色板。

下一步首先补齐验证，而不是继续堆叠功能：

- 合并模式与独立模式的完整视觉验收。
- 深色、浅色、透明、磨砂背景验收。
- 真实主题的导入、编辑、撤销、导出、重新导入闭环。
- ComfyUI Frontend / Vue Nodes / 浏览器版本矩阵。

## 后续：框架兼容性

- 在 ComfyUI Frontend 稳定版验证侧边栏加载。
- 验证传统 LiteGraph Canvas 的全部已知字段。
- 验证 Vue Nodes 开启和关闭时的差异。
- 增加运行时兼容性诊断面板。
- 修复不同浏览器的颜色控件差异。
- 建立字段到界面区域的验证记录。

## 后续：可用的主题实验室

- 提供内置预览工作流模板。
- 一键创建普通、选中、Bypass、错误、折叠节点状态。
- 参数变化时高亮受影响的真实节点或界面区域。
- 增加最近使用颜色和收藏色板。
- 增加对比度检查和可读性提醒。

## 后续：主题管理

- 接入稳定的 ComfyUI 自定义主题持久化接口。
- 另存为新主题。
- 更新当前自定义主题。
- 主题复制、重命名和删除。
- 多主题并排比较。

## 后续：版本与兼容

- 记录主题来源 Frontend 版本。
- 检测缺少字段、废弃字段和新增字段。
- 提供迁移报告。
- 为不同 Frontend 版本维护字段适配表。

## 后续：WorkspaceKit 系列整合

- 与 WorkspaceKit 主插件共享设置和品牌样式。
- 与 WorkspaceKit-Layout 协调侧边栏位置和宽度。
- 增加统一命令、快捷键和入口。
- 支持 WorkspaceKit 模块发现机制。

## 1.0.0：稳定发布条件

- 至少覆盖两个连续的 ComfyUI Frontend 稳定版本。
- 主题导入导出无字段丢失。
- 实时预览的已知字段通过测试矩阵。
- 持久化操作具备回滚和冲突处理。
- 中英文界面和文档完整。
